# 共用飞书应用模式（可选参考）

本文件为**备选方案**。当前团队采用 **每人独立应用**，见 [TEAM.md](TEAM.md)。

## 共用模式

| 组件 | 共享策略 |
|------|----------|
| 飞书自建应用 | 全团队共用一个（管理员创建） |
| App 凭证 | 加密渠道分发给每人，写入 `~/.feishu-mcp/config.env` |
| Wiki 协作区 | 管理员对应用分享一次 |
| `FEISHU_COLLABORATOR_OPEN_ID` | 每人不同 |

优点：飞书后台只维护一个应用。  
缺点：Secret 分发需管控；应用操作审计不区分个人。
